## 💼 Professional Experience

### Frontend Software Engineer — Cyient (Celfinet) | 2026 — Present

I help build **ng-UI**, a modern telecom network-management platform used by operators to plan, audit, and monitor mobile networks.

Main areas of work:

- Building network-planning tools, data-integrity audits, analytics dashboards, geographic maps, automation workflows, and AI-assisted features.
- Developing **React** and **TypeScript** applications in an **Nx monorepo** composed of **Module Federation micro-frontends**.
- Modernising the legacy **VisMon UI v3** platform, starting with the Network Planner, while preserving established business rules and backend services.
- Delivering reusable and accessible interfaces for large datasets, including filtering, sorting, pagination, and complex operational workflows.
- Leading the platform's internationalisation across English, Spanish, and Portuguese, with tooling and validation that keep translations consistent.
- Collaborating with backend engineers and product owners through **Azure DevOps**, code reviews, and pull requests; testing with **Vitest** and React Testing Library and deploying through **Octopus Deploy**.

### Frontend Software Engineer — Blaze | 2022 — 2026

At **Blaze**, I built scalable frontend platforms and customer-facing products for a fast-moving SaaS and e-commerce environment using **React**, **Next.js**, **TypeScript**, and micro-frontend architecture.

Main areas of work:

- Architected and implemented **React/TypeScript micro-frontends**.
- Integrating micro-frontends into host SPAs using **single-spa**, Parcel, and SystemJS import maps.
- Building host-to-MFE runtime communication for authentication, merchant/store context, user roles, themes, timezones, and routing configuration.
- Developing campaign management interfaces, campaign builders, and email/SMS configuration flows.
- Implementing complex forms with **React Hook Form** and **Zod**.
- Managing frontend state with **Zustand**, **Redux**, and Context API.
- Building API service layers with Axios, interceptors, authentication headers, and data transformation.
- Developing SEO-friendly pages with **Next.js SSR**, including metadata, dynamic routes, sitemaps, and robots.txt handling.
- Maintaining reusable UI components with **Storybook**.
- Creating and maintaining automated tests with **Cypress**, Jest, and React Testing Library.
- Supporting authentication flows, including social login integrations such as Google Sign-In.
- Contributed to code reviews, mentored junior developers, and improved engineering standards.

### Django Web Developer — Pack4Sustain | 07/2021 — 07/2022

- Developed and maintained web applications with **Django** and **Django REST Framework**, focusing on reliable backend services and maintainable application architecture.
- Designed and optimised **REST APIs** backed by **PostgreSQL**, improving data access and supporting integrations with external platforms and webhooks.
- Built tailored **Django Admin** interfaces that simplified content management and day-to-day operational workflows.
